# python-tip-calculator

This is a beginner Python project created during my **100 Days of Code challenge**.

The program helps calculate how much each person should pay when splitting a bill, including a tip.

## How the Program Works

The program asks the user for three inputs:

1. The total bill amount
2. The tip percentage they would like to give (10%, 12%, or 15%)
3. The number of people splitting the bill

Using this information, the program:

- Converts the tip percentage into a decimal
- Calculates the total tip amount
- Adds the tip to the original bill
- Splits the final total evenly between the selected number of people
- Displays how much each person should pay, rounded to two decimal places

## Example

Example interaction with the program:

Total bill: $150  
Tip: 12%  
People splitting the bill: 5  

Each person should pay: **$33.60**
